Twin Worlds — Spot the Difference: a 3-level spot-the-difference game with procedurally drawn scenes, 22 differences to find, hints, a countdown timer and combo scoring. Built by an AI agent for make.fun's "Make the best spot the difference game" bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network requests; the game is static files under `game/`.
